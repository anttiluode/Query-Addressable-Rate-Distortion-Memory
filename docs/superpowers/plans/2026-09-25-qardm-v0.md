# QARDM v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and falsify a small fixed-budget memory where query-aware rate-distortion allocation is compared fairly with reconstruction-aware and recency baselines.

**Architecture:** A deterministic NumPy world produces paired episodes plus independent calibration/evaluation query banks. A resident memory exposes exact scalar cost and four compression moves. Greedy allocators differ only in the loss used to price identical candidate moves, and a frozen experiment runner emits a JSON receipt across 12 seeds and two budgets.

**Tech Stack:** Python 3.10+, NumPy, pytest, standard-library dataclasses/json.

**Spec:** `docs/superpowers/specs/2026-09-25-qardm-v0-design.md`

## Global Constraints

- NumPy only for runtime computation; pytest for tests.
- CPU only; target runtime seconds, not minutes.
- 12 frozen seeds; 24 episodes as 12 twin pairs.
- Payload is 8 coarse + 4 fine coordinates.
- Same episode stream, calibration queries, evaluation queries, legal operations, and scalar budget for every allocator.
- `query_rd` never sees held-out evaluation queries.
- Primary gate: `query_rd` beats both `reconstruction_rd` and `recency` on held-out query MSE in at least 10/12 seeds at both budgets.
- No per-seed or post-result tuning.

## Review Focus

1. **Zero/near-zero candidate savings:** candidate operations with no scalar saving must never divide by zero or enter the greedy choice.
2. **All items forgotten/coarsened:** reader must return a deterministic zero payload when memory is empty and handle mixed-resolution items without shape errors.
3. **Merge accounting:** merging full and coarsened items must preserve the intersection of represented coordinates and count exact stored scalars.
4. **Calibration leakage:** evaluation queries must never be passed to allocation code; the runner should construct them separately and only score after allocation.
5. **Deterministic ties:** equal loss-per-scalar candidates must resolve by a stable operation key so receipts reproduce byte-for-byte apart from JSON formatting.

**Interfaces:**

- `Memory.scalar_cost()` counts stored key coordinates + represented payload coordinates + two scalar metadata values (`count`, `time`) for each item.
- `Memory.read(cue)` returns a payload vector using softmax address similarity; missing fine dimensions contribute zero.

```python
def test_coarsen_saves_exactly_four_payload_scalars():
    w = make_world(0)
    m = full_memory(w.episodes)
    before = m.scalar_cost()
    op = Operation("coarsen", (0,))
    after = apply_operation(m, op)
    assert before - after.scalar_cost() == 4
    assert np.allclose(after.items[0].payload[:8], m.items[0].payload[:8])
    assert np.all(after.items[0].present[8:] == 0)


def test_empty_memory_reads_zero():
    m = Memory(items=tuple(), payload_dim=12, temperature=0.20)
    assert np.array_equal(m.read(np.ones(4)), np.zeros(12))
```

Run: `pytest tests/test_memory.py -q`

- [ ] **Step 3: Implement immutable resident state and operations.** `forget` removes one item; `coarsen` removes fine coordinates; `merge` uses count-weighted means for key, represented payload coordinates, count, and time. Merge candidates are restricted to nearest key-neighbours so the search stays small and deterministic. Reading uses stable softmax over negative squared key distance.

- [ ] **Step 4: Implement metrics.** Reconstruction loss maps each original episode to its best resident representative by key distance and scores key+represented-payload error with missing payload coordinates treated as zero. Query loss computes mean squared error between stored query targets and `probe @ memory.read(cue)`.

def test_query_allocator_preserves_queried_fine_bit():
    w = make_world(1)
    budget = int(full_memory(w.episodes).scalar_cost() * 0.50)
    q = allocate_query(w.episodes, w.calibration, budget)
    r = allocate_reconstruction(w.episodes, budget)
    hot = {x.family for x in w.calibration if x.diagnostic}
    assert q.ledger["fine_items_in_hot_families"] >= r.ledger["fine_items_in_hot_families"]
